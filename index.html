Як упакувати сайт у кейс

Скріншот, запис анімацій, мобільна версія — і де все це публікувати. Всі способи в одному місці.

1
Крок перший

Скріншот всієї сторінки

Зберегти сайт одним довгим зображенням — для кейсу і портфоліо.

DevTools — покроково
  1. Відкрий сайт → натисни F12 (або Cmd+Opt+I на Mac)
  2. Натисни Ctrl+Shift+P (або Cmd+Shift+P) — з'явиться рядок пошуку команд
  3. Введи screenshot → вибери Capture full size screenshot
  4. Файл .png автоматично збережеться в Downloads
Якщо є fixed-елементи (sticky header тощо) — вони можуть дублюватися на скріншоті. В кейсі це не критично.
GoFullPage — встановлення і використання
  1. Chrome Web Store → знайди GoFullPage → «Додати в Chrome»
  2. Відкрий сайт → натисни іконку розширення у правому верхньому куті
  3. Воно само прокрутить сторінку і збереже як .png або .pdf
Може некоректно працювати з fixed-секціями та scroll-анімаціями. Якщо результат поганий — використовуй DevTools.

Крок другий

Запис анімацій і скролу

Записати відео як сайт виглядає в русі — найважливіша частина кейсу анімованого сайту.

Mac — Screen Record
  1. Натисни Cmd+Shift+5 — з'явиться панель внизу екрана
  2. Вибери Record Selected Portion або Record Entire Screen
  3. Натисни Record → запиши скрол → зупини кнопкою у menu bar зверху
  4. Файл .mov збережеться на Desktop
Windows — Xbox Game Bar
  1. Натисни Win+G → відкриється Game Bar
  2. Натисни Record, або одразу Win+Alt+R без відкриття панелі
  3. Запиши скрол → ще раз Win+Alt+R щоб зупинити
  4. Файл .mp4 в папці Відео / Captures
Game Bar не записує робочий стіл — лише вікна додатків. Переконайся що браузер не згорнутий.
iPhone — налаштування і запис
  1. Налаштування → Пункт управління → натисни + поряд з «Запис екрана»
  2. Свайп вниз з правого верхнього кута → натисни кнопку Record
  3. Відкрий сайт і прокрути
  4. Натисни червону кнопку вгорі щоб зупинити
Android — запис екрану
  1. Свайп зверху екрана → знайди Screen Record або «Запис екрану»
  2. Натисни → відкрий сайт і запиши скрол
  3. Зупини через панель швидкого доступу
Android до версії 11 — вбудованого запису немає. Використовуй емуляцію мобілки в Chrome DevTools (Ctrl+Shift+M).
OBS Studio — покроково
  1. Завантаж і встанови OBS → Sources → + → Display Capture (весь екран) або Window Capture (тільки браузер)
  2. Settings → Output → Recording Path — вибери куди зберігати файл
  3. Натисни Start Recording → запиши скрол → Stop Recording
  4. Файл .mkv або .mp4 збережеться у вказану папку
Краща якість ніж вбудовані інструменти. Підходить якщо потрібен великий файл для монтажу.

Крок третій

Мобільна версія

Показати як сайт виглядає на телефоні — обов'язково для повного кейсу.

Chrome DevTools — Mobile Emulation
  1. F12 → натисни іконку телефону у верхньому лівому куті (або Ctrl+Shift+M)
  2. Зі списку вибери пристрій: iPhone 14, Samsung Galaxy S20 Ultra тощо
  3. Скріншот: Ctrl+Shift+P → Capture screenshot
  4. Відео: запусти запис екрану поки відкрита мобільна емуляція
iPhone 14 Pro (393×852) виглядає найкраще в кейсах.
Реальний телефон
  1. iPhone: відкрий сайт в Safari або Chrome → запиши екран через Пункт управління
  2. Android: відкрий сайт → свайп зверху → Screen Record
Якщо сайт ще не задеплоєний — використовуй DevTools.
4
Крок четвертий

Де публікувати кейс

Instagram і Dribbble — дві основні платформи для веб-дизайнерів. Кожна під свою мету.

Instagram

Для аудиторії і клієнтів
  • Reels: запис скролу сайту — найкращий формат. 15–30 сек, вертикально 9:16.
  • Карусель: перший слайд — скріншот, далі деталі, мобілка, результат.
  • Підпис: що за сайт + які інструменти + CTA («посилання в шапці»).

Dribbble

Для портфоліо і нетворкінгу
  • Shot: один скріншот — обкладинка проєкту. Розмір 800×600 або 1600×1200.
  • Gif або .mp4: відео скролу виглядає набагато краще статики.
  • Опис: що за проєкт, стек (HTML/CSS/GSAP/Webflow), посилання на сайт.
  • Теги: web design, landing page, animation, ui design.
Instagram — для залучення нових клієнтів і аудиторії. Dribbble — для портфоліо яке показуєш за посиланням. Краще публікувати на обох.
